# Examination Cycle & Unavailable Papers Audit Report

## 1. 10-Year Recruitment History Analysis (2014 – 2026)
Unlike central government examinations (e.g., UPSC, SSC, CTET) which are administered on a fixed annual schedule, state government **Teacher Recruitment Tests (TRT / DSC)** in Telangana and Andhra Pradesh are **event-based notification drives** that are only authorized when state teacher vacancies are sanctioned by state cabinet orders.

| Year | Notification Status | Examination Status | Documentation & Justification |
| :---: | :---: | :---: | :--- |
| **2014** | Notified | **Exam Conducted (AP DSC 2014)** | Post-bifurcation unified syllabus exam held May 2015. Archived in repository. |
| **2015** | None | No Exam | Post-bifurcation administrative restructuring; no DSC notification issued. |
| **2016** | None | No Exam | No recruitment notification issued in either AP or TS. |
| **2017** | Notified | **Exam Conducted (TS TRT 2017)** | TSPSC Notification 52/2017; exam held March 2018. Archived in repository. |
| **2018** | Notified | **Exam Conducted (AP DSC 2018)** | AP TET-cum-TRT 2018; exam held Dec 2018 / Jan 2019. Archived in repository. |
| **2019** | None | No Exam | AP DSC 2018 cycle concluded; no new notification issued. |
| **2020** | None | No Exam | COVID-19 pandemic hiatus; schools closed nationwide; all recruitments halted. |
| **2021** | None | No Exam | COVID-19 pandemic recovery; no teacher recruitment tests conducted. |
| **2022** | None | No Exam | Only TET (Teacher Eligibility Test) conducted; no TRT/DSC recruited. |
| **2023** | None | No Exam | TS & AP TET held; DSC recruitments announced but delayed pending election codes. |
| **2024** | Notified | **Exam Conducted (TG DSC 2024)** | TG Mega DSC 2024 (11,062 posts); SA Maths exam held July 2024. Archived in repository. |
| **2025** | Ongoing | Notification Phase | AP Mega DSC notified; exam scheduled across 2025/2026 cycles. |
| **2026** | Projected | Recruitment Cycle | Upcoming recruitment cycle. |

## 2. Missing-Years Compliance Statement
As mandated by the Work Order guidelines:
* **No synthetic or fabricated papers** have been placed in the previous-year archives to fill non-recruitment years.
* Every verified official examination paper available in the 10-year window (2014, 2017/2018, 2018/2019, 2024) has been collected, transcribed into English, and paired with its verified official answer key.
* The non-occurrence of examinations in 2015, 2016, 2019, 2020, 2021, 2022, and 2023 is historically verified and documented above.
