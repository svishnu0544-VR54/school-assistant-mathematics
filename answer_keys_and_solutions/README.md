# Answer Keys and Solutions Central Repository

This directory consolidates master answer keys and solutions across all examination components:

1. **Master_Answer_Key_Matrix_All_200_Tests.csv**: Condensed key matrix mapping all 16,000 mock questions across all 200 mock examinations.
2. **Master_Question_Bank_and_Answer_Keys.csv**: Complete question bank with questions, options, difficulty ratings, verified keys, and full explanations.
3. **Previous Year Answer Keys**: Located in previous_year_papers/answer_keys/ with official keys for TG DSC 2024, AP DSC 2018, TS TRT 2017, and AP DSC 2014.
4. **Individual Test Explanations**: Each test folder in mock_tests/Mock_Test_XXX/ contains its dedicated explanations.md file providing comprehensive mathematical and pedagogical explanations.
